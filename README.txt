MINE EMPIRE V4 — INSTALLAZIONE IPHONE

1. Estrai lo ZIP sul computer.
2. Crea un repository GitHub e carica TUTTI i file nella cartella principale (root).
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Attendi la pubblicazione, poi apri l'URL GitHub Pages con Safari su iPhone.
5. Premi Condividi → Aggiungi alla schermata Home.

La PWA usa HTTPS, ha cache offline e salva i progressi localmente sul dispositivo. Esporta periodicamente un backup da ALTRO. Se aggiorni il gioco, pubblica i nuovi file e chiudi/riapri la PWA per caricare la nuova versione.

Mine Empire è un gioco originale ispirato al genere idle mining. Non è un prodotto ufficiale e non utilizza asset proprietari di Idle Miner Tycoon.
